# 纪念日倒计时 · Countdown

一个单文件的纪念日倒计时网页：暗色玻璃质感界面，可以自己添加、删除纪念日，数据存在浏览器本地，关掉再打开还在。

- 默认内置一个 **2027 年 1 月 1 日**
- 日期**精确到分**：表单里选日期 + 时间（`<input type="time">`），主卡和列表都显示到分钟
- 天 / 时 / 分 / 秒 实时倒数，秒针每跳一下有轻微呼吸感
- 「每年重复」：生日、周年这类日子不用每年重新加
- 已经过去的日子会显示「已经过去 N 天」，当天会显示「就是今天」
- **左侧倒计时卡下方随机风景照**：同一个纪念日永远是同一张，不同纪念日不一样；点「换一张」可以换，换过的那张会被记住
- 风景图加载不出来时（断网 / 图源被墙 / 图源卡住超过 10 秒）自动换成**代码绘制的风景**（按同一颗种子生成雪山、星空、日落），并标出「离线可用」
- 删除后有 **撤销** 提示条，手滑删错能马上恢复
- 六个主题色，选中哪条纪念日，整个页面的光晕就跟到哪
- 响应式：手机上主卡在上、表单在下，列表行会自动换成两行排版
- 没有任何构建步骤，没有任何外部依赖（字体不可用时回落到系统字体）

## 使用

直接双击 `index.html` 就能用。

想用本地服务器打开：

```bash
python -m http.server 8123
# 然后访问 http://127.0.0.1:8123/
```

## 数据存在哪

浏览器 `localStorage`，键名 `anniversary-countdown.v1`。
所以数据是**按设备、按浏览器**存的：换电脑、换浏览器、无痕模式都不共享。清空浏览器数据会一起清掉。
存储不可用时（比如无痕模式被禁），页面底部会给出提示。

## 风景图从哪来

- 照片来自 [Lorem Picsum](https://picsum.photos)（图源为 Unsplash 上可免费使用的照片），页面上会标出摄影师署名。
- 页面里内置的是**一份人工筛过的 30 张风景清单**：先批量拉缩略图拼成对照图，逐张看过题材，只留下山、海、湖、森林、荒野这类风景，剔除了人像、城市、静物。
- 每个纪念日按 `名称 + 日期 + 时间` 做哈希取一张，所以**同一个纪念日永远同一张**，不同纪念日基本不同；「换一张」是给这个纪念日加一个偏移量，选择会存进 `localStorage`。
- **需要联网**才能拿到照片。断网、图源被墙、或 10 秒还没加载出来，就会自动换成按同一颗种子生成的内嵌 SVG 风景（夜空有星星、按种子换天色），所以离线也不会空着。
- 想换成自己的图：改 `index.html` 里的 `SCENES` 数组（`{ id, by }`），`scenePix()` 负责拼图片地址即可。

## 测试

```bash
npm install   # 只为测试装 jsdom，页面本身不需要
npm test
```

`tests/dom.test.js` 用 jsdom 真实加载 `index.html`，驱动表单提交、列表点击、删除与撤销、换风景、图片加载失败，逐条断言渲染结果与持久化内容，覆盖：默认项、增删改查、日期时间、排序（今天 → 未来 → 过去）、重复规则、风景挑选与换图、离线兜底、空状态、旧数据兼容、坏数据自愈、以及名称不会被当成 HTML 解析。

## 部署

纯静态，扔到任何静态托管都行：GitHub Pages、Cloudflare Pages、Netlify、Vercel，或者自己的服务器。
GitHub Pages 的做法：仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后等一分钟。
